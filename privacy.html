Privacy policy

This policy describes VPS-Backup, a personal backup utility operated by the owner of the GitHub account barissirvanli. The Google Drive backup connection is being configured; automated offsite backups are not yet active.

Google data access and purpose

The utility uses Google OAuth authorization through rclone to access Google Drive for backup storage and recovery. It uses authorized file contents and file metadata to upload, list, verify, download and maintain its encrypted backup repository. Access is used only for these backup functions, not for advertising, profiling or training AI models. The intended configuration requests only access to files created or explicitly authorized for this utility; the actual requested permissions are displayed by Google during authorization.

Data storage and protection

Backup archives may contain the owner's server and application data. The planned Restic setup encrypts repository contents before transfer to Google Drive. Encrypted repository data and the file metadata needed to store it are held in the owner's Google Drive account. Local backup copies and operational logs may remain on the owner's server.

OAuth tokens and client credentials are needed by rclone for unattended access. They are to be kept in restricted configuration on the owner's server, separate from this public website and repository. Google account passwords are not collected. Encryption keys must be retained separately for recovery.

Sharing

The operator does not sell Google user data or use it for advertising. Google Drive processes uploaded backup data to provide storage. The server hosting provider supplies the infrastructure running the utility. No other person is intentionally given access to the Google account or backup contents by this utility.

Retention, deletion and revocation

A scheduled backup retention policy has not yet been configured. Until it is, uploaded test or backup data remains until the owner deletes it. Deleting a local copy does not automatically delete a remote copy, or vice versa. The owner can delete the Drive backup repository and local copies separately and revoke the utility's access in Google Account connections. Revoking access stops future authorized access but does not itself delete existing backups.

This website

This informational site does not contain a Google sign-in form, analytics scripts, advertising or forms for uploading personal data. GitHub Pages hosts the site and may process technical request information under GitHub's privacy statement.

Google API data policy

VPS-Backup's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact and updates

Contact the operator through the repository issue tracker. It is public; do not post sensitive data. This policy will be updated if the configured data access or backup practices change.
