VPS-Backup

VPS-Backup is a private utility operated by the owner of the GitHub account barissirvanli. It is being configured to store encrypted backups from the owner's server in the owner's Google Drive account and restore them when needed. It is not a public backup service and does not accept registrations.

How it works

The planned setup uses Restic to encrypt backup contents before upload and rclone to transfer the encrypted repository to Google Drive. Google authorization enables the utility to create, read, list and maintain backup files within the access granted by the account owner. Google account passwords are not collected by this utility.

Offsite backup scheduling and recovery testing are not yet complete. This informational site does not run the backup utility or request Google authorization.

Privacy and contact

Read the privacy policy for information about Google data access, storage, retention and revocation.

Questions can be submitted through this repository's issue tracker. Issues are public: do not include backup contents, credentials, authorization tokens or private server information.

Terms of use

This utility is for the owner's private use. This site provides information only, without a service availability or recovery guarantee. There is no public service, subscription or third-party account access offered here.
